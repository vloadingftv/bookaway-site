## Como ler os documentos daqui

Todo dado vem com **fonte** e **confiança**:

| Nível | Significa |
|---|---|
| 🟢 Confirmado | Fonte primária ou registro público (CNPJ, CVM, site oficial) |
| 🟡 Provável | Imprensa ou fonte secundária consistente, sem confirmação interna |
| 🔴 Hipótese | Inferência a partir de indício — precisa ser checada antes de virar decisão |

Dado sem fonte não entra. Se um número aqui contradiz o painel interno, **o painel interno vence**
e o documento é corrigido.
