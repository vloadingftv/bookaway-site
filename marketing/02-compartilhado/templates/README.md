# Templates

Copie, renomeie sem o `_` inicial e preencha. Não edite o template ao usar —
ele é o padrão do time.

| Template | Use quando |
|---|---|
| `_briefing-campanha.md` | Abrir qualquer campanha |
| `_briefing-criativo.md` | Pedir uma peça ao design |
| `_briefing-ads.md` | Subir mídia paga |
| `_plano-de-lancamento.md` | Lançar produto ou marca |
| `_relatorio-mensal.md` | Fechamento do mês |
| `_post-mortem.md` | Encerrar campanha |

Melhorou algo ao usar? Traga a melhoria de volta para o template.
