# Playbook — SEO e conteúdo

## Princípio

Conteúdo é ativo: continua trazendo tráfego depois de publicado. Mídia paga é aluguel.
Por isso conteúdo tem prazo, mas não tem pressa — publicar peça fraca só para
cumprir calendário deteriora o domínio inteiro.

## Fluxo

```
pauta → aprovação → pesquisa de palavra-chave → outline → texto →
revisão → compliance → publicação → distribuição → atualização
```

Publicar sem distribuir é metade do trabalho. Todo conteúdo publicado vira,
no mínimo: 3 posts sociais + 1 e-mail.

## Pesquisa de palavra-chave

| Critério | Regra |
|---|---|
| Volume | Existe busca real? |
| Intenção | Informacional, comparação ou transacional? |
| Dificuldade | Temos autoridade para competir? |
| Negócio | Quem busca isso pode virar cliente? |

Sem a última coluna, o time produz tráfego que não converte.

## Estrutura de página

- Um H1, que responde à busca.
- Resposta direta nos dois primeiros parágrafos.
- H2s cobrindo as perguntas relacionadas.
- Link interno para conteúdo âncora e para página de conversão.
- Meta description escrita à mão.

## Manutenção

Conteúdo financeiro envelhece rápido: taxa, regra tributária e cenário mudam.

- Revisar conteúdo âncora a cada 6 meses.
- Toda peça com número traz a data da informação.
- Atualizar bom conteúdo antigo rende mais que publicar novo mediano.

## Não fazemos

Conteúdo gerado em massa sem revisão, título que promete o que o texto não entrega,
dado sem fonte.
