# Playbooks

Como fazemos cada canal, valendo para as três marcas do EWZ Group. O que é específico de uma
marca fica em `01-marcas/<marca>/canais.md`.

| Playbook | Canal |
|---|---|
| [paid-media.md](paid-media.md) | Google, Meta, LinkedIn Ads |
| [seo-conteudo.md](seo-conteudo.md) | Blog, SEO, conteúdo âncora |
| [email-crm.md](email-crm.md) | E-mail, automação, base |
| [social-organico.md](social-organico.md) | Redes sociais |
| [parcerias-influencia.md](parcerias-influencia.md) | Influenciadores e parcerias |

Playbook é documento vivo: todo post-mortem que gera aprendizado atualiza o playbook
correspondente. Se nada muda aqui depois de uma campanha, o post-mortem foi decorativo.
